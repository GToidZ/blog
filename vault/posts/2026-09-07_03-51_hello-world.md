## The Blog
I built this [blog engine](https://github.com/GToidZ/dossari) with vibecoding entirely as a learning experience. I used GLM 5.3 Flash with OpenCode harness and [ponytail](https://github.com/dietrichgebert/ponytail) to implement everything from scratch. Claude is also used for designing extensions system for the markdown parser. The flow of blog generation is as follow:
1. I write things in my Obsidian vault.
2. The site generator aggregates the vault and passes each relevant markdown file to the parser.
3. The site lays sitemap according to spec.
4. A GitHub action publishes the site to Pages.

I applied some basic constraints to tech used, for example: Use `bun` as default runtime, use TypeScript strict mode as default. Then, I also apply design guidelines by myself which you can check in `AGENTS.md` in the repository.

Implementation is mostly done with vibecoding while I wrote the entire `AGENTS.md` file and `SKILL.md` for creating extensions is done by myself while Claude helped improving it.
