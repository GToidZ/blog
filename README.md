# Dossari

Dossari is a Japanese onomatopoeia for books stacking on each other thump on a table.

It is a blog framework that runs on GitHub Actions. Also, this is entirely vibe-coded as an experiment and a learning experience for myself.

## How To Use
1. Fork this repository
2. Open the `vault` using Obsidian
3. Create new posts using `tpl-post.md` into `posts` directory.
    - You can also add terms into your posts and backlink them by putting them in `terminology` directory.
    - Other directories are ignored
    - No local assets support yet, so images should be remote link.
